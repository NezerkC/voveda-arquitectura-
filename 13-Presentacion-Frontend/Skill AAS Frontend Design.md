# SKILL AAS: FRONTEND DESIGN (PRODUCTION GRADE)

```text
================================================================================
ROLE: Frontend Architect & Implementer
OBJECTIVE: Build production-grade frontend interfaces using modern stacks 
           (React, Tailwind, Shadcn/ui) strictly adhering to the design system.
================================================================================
```

## 1. Posición en el Flujo de Trabajo
Esta skill se ejecuta en la **Fase 3 (Patrones & Adaptadores)**. Es un "Driving Adapter" que interactúa con los puertos de entrada de nuestra Clean Architecture/Arquitectura Hexagonal.

## 2. Responsabilidades
- Convertir el sistema de diseño (tokens) en componentes reutilizables.
- Conectar las interfaces con los endpoints definidos por el `Agente OpenAPI`.
- Manejar el estado del cliente y la hidratación de Server Components.
- Evitar acoplar la lógica de negocio al componente visual.

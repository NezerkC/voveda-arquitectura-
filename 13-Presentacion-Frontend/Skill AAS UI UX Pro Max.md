# SKILL AAS: UI/UX PRO MAX

```text
================================================================================
ROLE: Professional UI/UX Designer
OBJECTIVE: Define design systems, typography, color palettes, and accessibility 
           standards before component implementation.
================================================================================
```

## 1. Posición en el Flujo de Trabajo
Esta skill se ejecuta al final de la **Fase 2** o inicio de la **Fase 3**. Consume los contratos visuales y de datos (OpenAPI/CDD) para armar los wireframes y el sistema de diseño base. **Nunca** debe inventar datos de negocio; solo representa lo que el Dominio entrega.

## 2. Responsabilidades
- Establecer guías de estilo y tokens de diseño.
- Garantizar contraste, legibilidad y accesibilidad (WCAG).
- Diseñar la jerarquía visual de la aplicación.

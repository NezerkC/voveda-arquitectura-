Paso 1 👤

Usuario / Stakeholder

Paso 2 📋

Agente Product Manager

Entrevista guiada. Descubrimiento de reglas de negocio y PRD.

Skill de Inicio Multiagente (3 Roles)

start-new-project

Orquesta el onboarding guiado, redacción del PRD, refinamiento ágil de historias y disparo del desarrollo técnico.

Cadena de Ejecución:
Agente Product Manager → Agente Scrum Master → Agente Orquestador
Entregables: docs/PRD.md, docs/BACKLOG.md
Fase 1: Dominio Multiagente (3 Fases)

skill-ddd-domain-design

Modela el corazón del negocio y sus invariantes en código puro, completamente aislado de frameworks y bases de datos.

Cadena de Ejecución:
Agente BDD → Agente DDD → Agente CDD
Directorio destino: src/domain/
Fase 2: Arquitectura Multiagente (3 Fases)

skill-clean-hexagonal-scaffold

Construye la arquitectura en capas (Puertos y Adaptadores), Casos de Uso y validación estricta en runtime.

Cadena de Ejecución:
Agente Hexagonal / Clean → Agente Runtime Validation → Agente Lenguaje
Directorios destino: src/application/, src/infrastructure/
Fase 3: Datos Multiagente (4 Fases)

skill-resilient-persistence

Esquema relacional normalizado con migraciones, tabla Outbox transaccional, idempotencia y circuit breakers.

Cadena de Ejecución:
Agente PostgreSQL → Agente Outbox → Agente Idempotencia → Agente Retries
Directorio destino: src/infrastructure/persistence/, migrations/
Meta-Skill Maestra End-to-End (5 Fases)

production-project-architect

Orquestador de alto nivel que encadena todas las fases anteriores para construir y desplegar un proyecto enterprise completo.

Pipeline Completo:
Dominio (DDD) → Capas (Clean) → Datos (Postgres/Outbox) → Tests (TDD) → CI/CD (Docker)
